# 🚀 Sistema POS Industrial Sci-Fi

Un sistema de Punto de Venta (POS) con interfaz de usuario futurista en modo oscuro, empaquetado como aplicación nativa de escritorio para Windows utilizando Python, Flask y PyWebView.

<p align="center">
  <img src="hojita.ico" alt="Hojita Logo" width="128"/>
</p>

## 🛠️ Características Principales
- **Interfaz Dark Mode / Sci-Fi**: Estética futurista con HTML/CSS/JS.
- **Backend Robusto**: Base de datos SQLite (`pos_database.db`) gestionada con Python y Flask.
- **Ventana Nativa de Escritorio**: Ejecutado mediante `PyWebView` sin depender de navegadores externos.
- **Gestión e Historial**: Generación e historial de ventas con reportes diarios exportables en `.txt` y `.csv`.

## 📦 Ejecución y Distribución
El ejecutable binario para Windows se empaqueta mediante PyInstaller con todos sus recursos integrados y su icono personalizado.
